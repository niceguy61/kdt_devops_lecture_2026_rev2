app.py 한 글자를 고치고 다시 빌드하면

좋은 순서 — 1~2초

FROM python:3.14-slim
CACHED
RUN useradd
CACHED
COPY requirements.txt
CACHED
RUN pip install (20초+)
CACHED
COPY app.py
바뀜
코드를 맨 위(마지막)에 — 설치는 재사용

나쁜 순서 — 20초 이상

FROM python:3.14-slim
CACHED
RUN useradd
CACHED
COPY app.py requirements.txt
바뀜
RUN pip install (20초+)
다시 실행
코드가 설치보다 아래 — 위층인 설치를 매번 다시

규칙: 거의 안 바뀌는 것 → 의존성 목록 → 설치 → 코드 · 한 층이 바뀌면 그 위는 모두 다시
