DOCKERFILE (위에서 아래로)
이미지의 층 (아래에서 위로 쌓인다)
FROM python:3.14-slim
베이스 층들
WORKDIR /app
폴더 하나
RUN useradd … appuser
사용자 생성
COPY requirements.txt .
의존성 목록
RUN pip install …
라이브러리 (가장 큼)
COPY app.py .
내 코드 (몇 kB)
USER · ENV · EXPOSE · CMD
설정 (0B)

RUN = 빌드할 때 (밀키트 포장)

CMD = 실행할 때 (조리 방법) · PID 1

EXPOSE = 안내문 · 포트를 열지 않는다
