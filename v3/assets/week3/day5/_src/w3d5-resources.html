"최소 이만큼은 있어야 해" — 노드의 남은 예약 가능량과 비교해 놓을 곳을 정한다

limits — 상한 (커널이 지킨다)
CPU 넘으면느려진다 (throttling) — 죽지 않는다
메모리 넘으면죽는다 — OOMKilled · Exit 137
메모리는 늘려 줄 수 없는 자원 — 넘는 순간 커널이 프로세스를 끝낸다

requests 없음 = 스케줄러가 0으로 친다 → 한 노드에 몰려 서로 굶긴다
