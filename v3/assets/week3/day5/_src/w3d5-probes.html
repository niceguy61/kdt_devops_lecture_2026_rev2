startupProbe
묻는 것 — 다 켜졌나? (느린 앱)실패하면 — 아직 다른 probe를 시작하지 않는다
켜지는 데 1분 걸리는 앱용
readinessProbe
묻는 것 — 손님 받을 준비가 됐나?실패하면 — Service 목록(EndpointSlice)에서 뺀다 — 죽이지 않는다
order-api → /ready (DB · 큐)
livenessProbe
묻는 것 — 살아 있나? 멈추지 않았나?실패하면 — kubelet이 컨테이너를 다시 시작한다
order-api → /health (이 프로세스만)

2일차 2교시: /health = liveness, /ready = readiness — 이제 Kubernetes가 직접 묻는다

/ready를 liveness에 쓰면 → redis가 잠깐 죽을 때 모든 order-api가 재시작되는 2차 사고
