# 1주차 2일차 — 컴퓨터와 운영체제, 가상화

## 오늘의 목표

어제는 클라우드를 "빌려 쓰는 서버"라고 배웠습니다. 오늘은 그 서버 **안쪽**을 열어 봅니다. 클라우드에서 만나는 EC2 인스턴스, Docker 컨테이너, Kubernetes 파드는 모두 결국 **CPU 위에서 돌아가는 프로세스**이고, **운영체제**가 그 프로세스를 관리합니다. 오늘 배우는 내용은 5주 내내 "지금 무엇이 실제로 돌아가고 있는가?"를 판단하는 기준이 됩니다.

- 컴퓨터를 이루는 부품(CPU, 메모리, 디스크, 네트워크 카드)의 역할과 속도 차이를 설명할 수 있습니다.
- 운영체제와 커널이 하는 일을 설명하고, 서버에 왜 Linux를 쓰는지 말할 수 있습니다.
- 프로그램, 프로세스, 스레드를 구분하고 종료 코드의 의미를 압니다.
- 파일시스템, 경로, 권한을 읽을 수 있고, 블록·파일·객체 스토리지를 구분합니다.
- 기본 Linux 명령의 출력을 읽고 무엇을 확인하는 명령인지 말할 수 있습니다. (강사 시연)
- 하이퍼바이저의 두 종류를 구분하고, VM과 컨테이너의 차이를 설명할 수 있습니다.
