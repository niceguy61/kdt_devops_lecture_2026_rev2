## 오늘의 목표

어제 배움일기의 마지막 질문은 "내일 다시 만들면 **정말로 30분 안에** 같아질까? 그리고 **노드 하나가 죽으면** db는 어떻게 될까?"였습니다. 오늘은 과정의 마지막 날입니다. 5주 동안 쌓은 것을 **한 번에 돌리고**, 클라우드에서 **장애를 일으켜 보고**, 계정을 **깨끗이 비운 뒤**, 다섯 주를 돌아봅니다.

- 1주차부터 5주차까지를 **한 장의 지도**로 묶습니다.
- 스크립트 하나로 EKS 위의 DevMart를 **처음부터** 다시 세우고 시간을 잽니다.
- **커밋 하나**가 kind와 EKS **두 클러스터**에 함께 배포되는 것을 봅니다.
- 노드를 죽이고 AZ 하나를 막아, **상태 없는 것과 상태 있는 것**이 어떻게 다르게 회복하는지 봅니다.
- 모든 것을 지우고 **모든 리전에서** 남은 것을 찾고, 이번 주 비용을 보고합니다.
- 5주를 회고하고, 저장소 셋을 **포트폴리오**로 정리하고, 다음 걸음을 정합니다.
